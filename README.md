Portfólio profissional desenvolvido para apresentar minha trajetória, conhecimentos técnicos e projetos na área de desenvolvimento de software.

O projeto foi desenvolvido com HTML5, CSS3 e JavaScript, contemplando boas práticas de desenvolvimento Front-End, responsividade, acessibilidade, SEO, testes e publicação.

## Qualidade de software — QA

A qualidade foi considerada durante o desenvolvimento, com verificações, identificação de problemas, correções e retestes.

### Ferramentas de teste

**Google Chrome DevTools**
- Console: investigação de erros JavaScript.
- Elements: inspeção da estrutura HTML e dos estilos CSS.
- Device Toolbar: simulação de diferentes dimensões de tela.

**Google Lighthouse**
- Avaliação de desempenho.
- Avaliação de acessibilidade.
- Avaliação de SEO.
- Verificação de boas práticas.

## SEO e acessibilidade

Foram consideradas práticas como:

- Estrutura HTML semântica.
- Metadados e descrições das páginas.
- Organização hierárquica dos títulos.
- Textos alternativos para imagens.
- Verificação de legibilidade e apresentação visual.
- Avaliação com Lighthouse.

## Segurança e boas práticas

Durante o desenvolvimento, foram considerados cuidados como:

- Organização e separação dos arquivos.
- Não inclusão de credenciais ou tokens no código público.
- Revisão dos scripts e recursos utilizados.
- Uso consciente de recursos externos.

Não foi realizada auditoria especializada ou teste de invasão. As verificações de segurança aqui descritas correspondem a cuidados básicos de desenvolvimento.

## Publicação

O portfólio foi publicado utilizando GitHub Pages.

Fluxo de desenvolvimento:

1. Desenvolvimento local no Visual Studio Code.
2. Implementação de HTML, CSS e JavaScript.
3. Verificações funcionais e visuais no navegador.
4. Inspeção e depuração com Chrome DevTools.
5. Avaliação de qualidade com Lighthouse.
6. Versionamento com Git e GitHub.
7. Publicação e validação da versão hospedada.
